# 🧸 Buddy - AI English Learning Chatbot for Kids

An AI-powered English learning chatbot for children under 7, built with Streamlit and Groq (Llama 3.1 8B Instant).

## Features
- Progressive levels: L1, L2, L3 with mastery-based promotion
- Child mode detection: LEARNING, CONVERSATION, ENGAGEMENT, SUPPORT
- Social and Emotional Learning (SEL) directives
- Context-aware responses using conversation history and child profile
- Sub-2-second latency with Groq + fallback responses
- Child-safe input/output filtering
